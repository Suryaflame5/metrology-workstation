Technical Documentation & User Manual

1. Getting Started

  1. Download and run Metrology-Workstation-v1.0.0-Windows-x64-Setup.exe.
  2. Launch Metrology Workstation from your Start Menu or Desktop.
  3. Your default browser opens automatically to http://127.0.0.1:8000.
  4. Navigate to "Calibration Studio" $\to$ select an instrument procedure (e.g. Outside Micrometer 0–25 mm).
  5. Enter nominal values, recorded readings, and environmental conditions $\to$ Click "Calculate Uncertainty & Decision".

2. GUM Mathematical Formulation

Combined standard uncertainty $u_c(y)$ is evaluated under JCGM 100:2008: 

u_c(y) = sqrt( sum( (c_i * u(x_i))^2 ) + 2 * sum_i sum_j (c_i * c_j * u(x_i, x_j)) )

Effective degrees of freedom $\nu_{\text{eff}}$ are computed via the Welch-Satterthwaite relation: 

nu_eff = u_c(y)^4 / sum( (c_i * u(x_i))^4 / nu_i )

3. ANSI/NCSL Z540.3 Method 6 Guardbanding

Method 6 applies dynamic root guardbanding $g$ based on the Test Uncertainty Ratio ($\text{TUR} = \frac{U_{\text{spec}}}{2 u_c}$):

  • When $\text{TUR} \ge 4.0$: Guardband $g = 0$ (Binary acceptance permitted; consumer risk $\le 2\%$).
  • When $\text{TUR} < 4.0$: Exact root guardband $g = u_c \cdot \Phi^{-1}(1 - P_{\text{CR}})$ is applied to reduce the acceptance interval: $A = [-\text{USL} + g, +\text{USL} - g]$.
